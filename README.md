# IRONFALL · 钢铁远征

> 工业星际远征背景的第一人称射击肉鸽游戏。
> **Apex 风格的强化运动系统** + **R-99 手感的武器系统** + **程序化生成的可替换地图**。
> 纯 WebGL2 + 原生 ES Modules，**零第三方依赖、零构建步骤**。

```bash
git clone https://github.com/tsingovo/ironfall.git
cd ironfall
node tools/serve.mjs          # 需要 Node 18+；无需 npm install
# 浏览器打开 http://127.0.0.1:8080/
```

进入战场后画面中央会提示「点击进入战场」——**点一下画面**锁定鼠标才能转视角（浏览器安全限制）。
按 `Esc` 打开菜单（不冻结游戏，视角仍可转），`Tab` 直接开设置。

> **关于 `Ctrl+W` 误关窗口**：`Ctrl+W` / `Ctrl+T` / `F11` 是浏览器保留快捷键，网页无权限拦截。
> 本作用 Chrome/Edge 的 **App 独立窗口**运行（没有标签栏与地址栏），从根上避免误触。

> 自测需要本机有 Chrome/Edge；若装在非常规位置，用 `CHROME_PATH` 环境变量指定可执行文件。

许可：**MIT**，见 [LICENSE](LICENSE)。设计与交接文档见 [`docs/`](docs/)。

## 1. 快速开始

Windows 下推荐直接双击：

```text
启动独立窗口游戏.cmd
```

也可双击同目录的短名入口 `开始游戏.cmd`。启动器会自动开启可复用的本地服务器，并用 Chrome/Edge 的
**App 独立窗口 + 自动最大化模式**运行游戏：没有标签栏和地址栏，且关闭横向滑动返回/前进。
每次启动只会重启 `%LOCALAPPDATA%\IRONFALL\app-profile` 对应的专属浏览器进程，避免隐藏残留进程吞掉窗口请求，绝不影响日常 Chrome 标签页；诊断记录写入 `launch.log`。
首次启动会创建独立配置目录 `%LOCALAPPDATA%\IRONFALL\app-profile`。

也可以用普通浏览器调试：

```bash

node tools/serve.mjs              # 启动静态服务器（默认 8080，可传端口）
# 浏览器打开 http://127.0.0.1:8080/
```

> 建议 Chrome / Edge 最新版（需要 WebGL2）。点一下画面获取指针锁定后即可游玩。

## 1.1 关于鼠标锁定（第一次玩必读）

游戏会在开始远征时请求锁定鼠标，这是浏览器的安全限制（防止网页劫持光标）。流程：

1. 首屏是**开始界面** → 按 `1` 或点击「开始远征」。
2. 独立启动器会自动最大化窗口；普通浏览器页会请求全屏。开始游戏后会请求鼠标锁定，系统光标隐藏，屏幕上只剩 HUD 准心。
3. 若浏览器拒绝锁定，可直接点击游戏画面重试；锁定不可用时会自动启用降级视角。

按 `Esc` 会**真正暂停游戏、释放鼠标并直接打开设置菜单**；再次按 `Esc` 或选「返回」会恢复游戏并尝试重新锁定鼠标。
若浏览器拒绝自动重锁，再点一下画面即可恢复。

> 如果点击后仍然不能转视角：检查浏览器是否给了指针锁定权限（地址栏左侧图标），
> 某些浏览器扩展或远程桌面环境会阻止指针锁定。

### 浏览器保留快捷键（网页拦不住）

| 组合 | 说明 |
|---|---|
| `Ctrl+W` / `Ctrl+T` / `Ctrl+N` | 关闭/新建标签页 —— **浏览器优先，无法拦截** |
| `F11` | 全屏切换 —— 无法拦截 |
| `F12` | 开发者工具 —— 我们**故意不拦**，方便你调试 |

其余常见误触组合（`F5` 刷新、`Ctrl+S` 保存、`Ctrl+P` 打印、`Ctrl+D` 收藏、`Ctrl+F` 查找、
`Backspace` 后退、`Tab` 焦点跳转、`空格` 滚动、方向键滚动）在**游玩中会被吞掉**；
在菜单/暂停状态下则**不拦截**，方便你刷新页面。

## 2. 操作说明

游戏内按 **`5`（主菜单）或暂停后选「操作说明」** 可查看完整键位表。

| 操作 | 按键 | 说明 |
|---|---|---|
| 移动 | `W A S D` | 相机相对 |
| 疾跑 | `Shift`（切换式） | 有加速斜坡，约 0.34s 到满速 |
| 跳跃 | `Space` | 支持土狼时间、跳跃缓冲、可变跳高（提前松键跳得矮） |
| 二段跳 | 空中再按 `Space` | 附加方向推力 |
| 冲刺 | `左 Alt` | IRONFALL 额外能力；空中次数有限，落地/蹬墙刷新 |
| 蹲 / 滑铲 | `Ctrl` 或 `C` | 高速按下从当前速度进入滑铲；平地不凭空加速，下坡会自然加速 |
| **蹬墙跑** | 贴墙 + 保持速度 | **按住 `Space` 可转成墙爬** |
| 蹬墙跳 | 蹬墙跑中按 `Space` | 上抛 + 离墙 + 沿墙前进方向三合一 |
| 攀爬翻越 | 朝台阶/沿口推进 | 高度 ≤2.35m 自动登顶 |
| 抓钩（战术技能） | `Q`（按一下） | Apex 风格战术键；自动保持牵引，弹簧式摆荡，**保留动量**；再次按 Q 或蹲下脱离 |
| 开火 | 鼠标左键 | 全自动 |
| 开镜 | 鼠标右键 | 降低扩散与移动速度，FOV 收缩 |
| 换弹 | `R` | 空仓换弹更慢；可被切枪打断 |
| 武器槽 | `1` / `2` / `3` / `4` / 鼠标滚轮 | 1 R-99、2 平行步枪、3 动力拳套、4 额外武器（默认哨兵） |
| 背包 | `Tab` | 6×4 搜打撤式背包；拖动整理，右键或拖出面板丢弃 |
| 治疗 / 护盾电池 | `5` | 轻按使用当前选项（不会因残血自动切药）；长按打开轮盘，鼠标左移选左侧医疗包、右移选右侧护盾电池，松开使用 |
| 互动 | `E` | 优先拾取附近地图物资；补给站可补满生命、护盾、全部弹药并打开免费改件货架 |
| 升级选择 | `1` `2` `3` | 也可鼠标点击；`R` 重掷；`Esc` 跳过 |
| 暂停 | `Esc` | 同时释放鼠标 |
| 调试面板 | `F3` | FPS / 帧时间 / draw call / 实体数 |

治疗读条开始会播放使用音效，完成后会播放独立确认音；被开火、开镜、换弹或切枪打断时不会恢复生命/护盾。

```
开始界面(main) ─┬─ 1 开始远征 ──→ 进入战场（点画面锁鼠标）
                ├─ 2 继续（有存档时）
                ├─ 3 远征简报  ← 剧情背景 + 本局任务
                ├─ 4 设置      ← 灵敏度 / 狙击镜灵敏度 / FOV / 音量 / Y轴反转 / 帧率上限 / 画质
                ├─ 5 操作说明  ← 完整键位表
                └─ 6 制作名单

战场中 ─ Esc ─→ 暂停(pause) ─┬─ 继续 / 设置 / 操作说明 / 放弃远征
                              └─ 切换到别的窗口会自动暂停

阵亡 ─→ 阵亡结算(dead)（含本局统计）
        └─ 12 秒倒计时后自动重新部署；也可按 1 立即重生 / 2 回主菜单
```

窗口失焦会**自动暂停**（否则切出去会在后台被打死）。

## 3. 运动系统（项目核心）

设计原则：**所有加速都作用在"速度矢量"上，重力只影响 Y**，因此水平动量可以被长期保留 ——
这正是滑铲、蹬墙跑、连跳爽感的来源。

| 机制 | 实现要点 |
|---|---|
| 基础移动 | Quake 风格 `accelerate()`，带 `stopSpeed` 摩擦 |
| 空中变向 | 「速度矢量对齐」：垂直速度与期望方向夹角越大，越能换取转向（tap-strafe 手感），同时用投影速度上限保留动量 |
| 滑铲 | 严格继承触发瞬间速度，不再无条件注入初速；下坡摩擦降低并沿真实坡面加速；低姿态相机与碰撞高度 |
| 蹬墙跑 | 重力降到 3.0 m/s²、向墙吸附、沿墙加速、时长上限、相机向墙侧滚转；松开方向键或按离墙方向立即脱离 |
| 蹬墙跳 | 离墙 + 上抛 + 沿墙前进方向冲量，并保留 40% 原有水平速度 |
| 墙爬 | 贴墙按住前 + 跳跃，可銜接翻越 |
| 抓钩 | 自动收绳弹簧力 + 抵消 62% 重力 + 轻微速度增益 → 摆荡；按键触发后无需持续按住 |
| 边坡 | 下坡沿坡面加速、上坡衰减；陡壁自动滑落 |
| 跳跃手感 | 土狼时间 0.14s、跳跃缓冲 0.16s、连跳保留水平速度并有 3.5% 增益 |
| 碰撞 | 线段+半径胶囊 vs 三角形/AABB（覆盖柱体与两端半球）；高速用球体扫掠防穿透；迭代推出解算 |
| 相机 | 眼高随姿态插值、速度 bob、落地弹簧下沉、多通道震动、速度/冲刺/开镜 FOV 叠加 |

**所有参数集中在 `src/core/config.js` 的 `CFG.move`**，改数值即可调手感。

### 构建期抓到的一个关键 bug（值得记住）

`m4ViewFromDir` 里前方向 `f` 与上方向 `u` 复用了同一块暂存数组，
导致计算 `u` 时把 `f` 覆盖掉，第三基向量取到的是 `u` —— 视图矩阵退化成奇异矩阵
（透视行变成 `[0,y,0,z]`），**结果是整个 3D 场景什么都画不出来，但 GL 不报任何错误**。
现在三个基向量各用独立暂存，并在源码里写了警告注释。`tools/test-modules.mjs` 会校验矩阵契约。

### 实机反馈修掉的问题（第二轮）

玩家实测反馈的问题，全部定位到根因并加了回归用例（`tools/test-ui-input.mjs`）：

| 现象 | 根因 | 修法 |
|---|---|---|
| **没有开始界面/设置/操作说明** | `hud.css` 用 **ID 选择器**写基准态（`#menu-overlay{opacity:0}`），状态类 `.menu-overlay--on{opacity:1}` 特异性更低，**永远赢不了** → 元素在 DOM 里、类也加上了，就是 `opacity:0` 看不见 | 新增 `styles/hud-fixes.css`，用 `#id.class`（特异性 1,1,0）显式覆盖；`test-modules.mjs` 增加**CSS 特异性守卫**，同类问题共发现 8 处（目标进度 / 撤离倒计时 / 换弹提示 / 连杀计数 / 交互提示 / F3 调试面板 / 升级面板 …） |
| **没有音效** | `AudioContext` 必须在用户手势的**同步调用栈**内创建/恢复，首次 resume 被拒后就一直 `suspended`，且不报错 | 音频初始化挂在输入层的「首次手势」钩子上；游戏循环每 32 帧调 `Audio.revive()` 兜底；`Audio.contextState()` 可查状态 |
| **鼠标不跟随** | 指针锁定请求带了 `{unadjustedMovement:false}`，部分浏览器直接抛 `TypeError`，于是完全没锁定 | 去掉该参数、失败时降级重试；点击画布即重新锁定；锁定彻底不可用时自动切到「无锁定鼠标视角」兜底；已删除会卡死的进入战场遮罩 |
| **两个准心** | 未锁定指针时系统光标与 HUD 准心叠在一起 | 原生锁定/正常游玩时隐藏系统光标；仅在无锁定降级模式恢复系统准心 |
| **没有按键保护** | 只拦了 `Space/Tab/方向键`，`F5`、`Ctrl+S` 等照样触发浏览器行为 | 游玩中吞掉 `F5`/`Backspace`/`Ctrl+S\|P\|D\|F\|O` 等；**菜单中不拦**（方便刷新）；`F12` 始终保留 |
| **瞄准方向反了** | 水平轴曾重复取反；之后 Y 轴又把 DOM“向下为正”的 `movementY` 多取反一次，导致鼠标向上反而低头 | 水平轴只在输入层按坐标系转换一次；Y 轴默认直接映射 `movementY`，开启“Y 轴反转”时才取反。自动化验证向上/向下两条路径 |
| **出生/行走时在地面之下** | 「沿最深接触法线迭代推出」在夹角/薄板几何下会把胶囊推到地形**下方**，推出式解算没有"最终位置必须合法"的保证 | 新增 `world.enforceCapsuleValidity()` 后置校验：抬出地形 + 只接受朝上的盒体纠正 + 再兜一次地形 |
| **看不到枪和手臂** | 实例批次绘制始终从 VBO offset 0 读矩阵；不连续同 mesh 批次又被错误回头合并；视图模型排队后恢复了世界相机才真正 `flush()`。另外旧 FOV/锚点也偏出屏 | 修正每批实例字节偏移，只合并紧邻同状态批次；世界与视图模型分成两个立即提交的 pass；FOV 提到 85°并重摆锚点。像素测试实测枪+手臂覆盖约 49 万像素 |
| **没看见敌人** | 同一实例批次偏移 bug 让敌人读取地形矩阵；同时旧刷怪逻辑偏向视野外，低对比配色又与地图融为一体 | 修复实例绘制；开局在前方 14~26m 生成遭遇；六兵种改高饱和配色并开启服从遮挡的高亮标记；着色器增加最低环境亮度。开局 6/6 位于前方、5/6 在视锥内 |
| **看不到子弹轨迹** | 实例偏移错误叠加曳光过细、过短 | 修复批次；曳光改为“深色宽轮廓 + 高饱和彩色光带 + 白色亮芯”三层并保证最短长度；纯黑 framebuffer 隔离测试实测 514 个可见像素、峰值 255 |
| **Esc 菜单反复开关/窗口缩小** | Game 与 HUD 同时监听 Escape；独立窗口又叠加网页 Fullscreen API，浏览器会先退出网页全屏、只解除指针锁而吞掉 keydown | Escape 改由 Game 单一状态机处理并直接打开设置；监听 `pointerlockchange/fullscreenchange`；独立 App 窗口不再叠加网页全屏，自动最大化且 Esc 不改变窗口尺寸 |
| **模型/地板像透明** | 高度场、圆柱、圆盘和楔形部分三角绕序朝内，开启背面剔除后正面被 GPU 丢弃 | 统一修正 CCW 绕序与外向法线；渲染地形和碰撞地形同步改为朝上；高亮标记恢复深度测试，不再透视墙体/地板 |
| **敌人太小** | 旧实现用含糊的全局缩放，模型与玩家尺寸关系不明确 | 普通人形敌人统一为和玩家相同的 1.8m 站立高度；重装、无人机和虫群保留兵种体型；碰撞胶囊、分层命中盒、枪口高度与模型同步 |
| **子弹看不见** | 玩家曳光只有约 0.08 秒，敌人即时射线完全没有可视弹道；曳光还从相机原点起绘，近裁剪不稳定 | 玩家曳光改从真实枪口出发并延长至 0.22–0.32 秒；光晕/白芯加粗；敌人每发即时射线也绘制有来向提示且在相机前截断 |
| **敌人伤害太高** | 多个兵种点射/连射伤害按原值叠加，开局多人齐射会瞬间击穿 175 点资源 | 敌方全局伤害降至原值 35%，保留兵种、难度和层级差异，显著增加反应与撤退窗口 |
| **补给站不补给 / 弹匣太小** | 旧交互只打开货架，三把主力枪弹匣只有 20–26 发 | 补给站补满生命、护盾、弹匣和备弹；R-99、Flatline、Volt 基础弹匣统一 35 发并同步完整后坐力序列；所有武器备弹无限 |
| **右键只看到枪屁股** | ADS 锚点离独立视图模型相机太近 | 所有武器 ADS 锚点前移；普通枪显示光学环/十字亮点，长弓显示圆形瞄准镜暗角 |
| **贴墙后无法脱离 / 静止时缓慢漂移** | 扫掠球半径过大且离墙速度也被裁剪；浅三角法线持续施加坡力 | 扫掠半径回到胶囊半径，仅裁剪朝墙速度；松开/反向输入退出墙跑；低于 2° 的法线噪声不施加坡力 |
| **R-99 枪口焰遮挡视野 / 破盾音不明显** | 高射速叠加枪口焰，破盾只有普通金属声 | R-99 关闭枪口焰；破盾加入高频玻璃碎裂层并提高增益 |
| **任务地点不明确** | 只有顶部方位文字，没有屏幕空间目标 | 增加任务名称、距离、屏内菱形与离屏左右箭头；撤离点使用独立蓝色样式 |
| **环台楼梯难爬** | 程序化台阶单级可高达 1.4m，远超 0.46m 跨步 | 单级高度限制为 0.58m，玩家自动跨步提高到 0.64m，地图全量连通性仍通过 |
| **岩浆与地面无差异 / 白地过曝** | 危险区只有伤害 AABB；地形生成了颜色但渲染时遗漏实例 tint，最终按纯白绘制 | 恢复生物群系地表 tint；危险区增加按类型配色的无光照表面、四边警戒条和中心标记 |
| **强化弹窗无法退出** | 合金不足时三个选项全锁，界面没有跳过入口；Esc 又会在背后打开设置 | 新增“跳过并继续 (Esc)”按钮；Esc 优先关闭强化货架并恢复输入，绝不叠加第二层菜单 |

同时补齐：**阵亡结算 + 12 秒自动重生倒计时 + `retryRun()` 手动重生**、
**「远征简报」剧情面板**、**制作名单**。

### 关于浏览器快捷键（务必知道）

`Ctrl+W` / `Ctrl+T` / `Ctrl+N` / `F11` 属于**浏览器保留快捷键，网页没有任何权限拦截**
（`preventDefault()` 只能阻止页面自己的默认行为，拦不住浏览器 UI 动作）。
游戏里能做的都做了：游玩中吞掉 `F5`/`Ctrl+S`/`Ctrl+P`/`Ctrl+D`/`Backspace`/`Tab`/`空格`，
并在 `Ctrl+W` 上不做无意义的拦截尝试。想尽量避免误触，直接双击项目根目录的
**`启动独立窗口游戏.cmd`**。它使用 Chrome/Edge App 独立窗口（无标签栏/地址栏）并关闭横向滑动导航。
注意它仍基于 Chromium，`Ctrl+W` 仍可能关闭整个游戏窗口；网页无法获得系统级快捷键控制权。

### 关于测试方法论的一条教训

前两轮我写了大量"内部状态断言"（`vm.items.length === 12`、`enemies.all.length === 5`），
它们全都通过，但**玩家依然看不到枪和敌人** —— 因为状态正确不等于画面正确。
这一轮补的测试改为直接验证**帧缓冲像素**与**投影几何**：

- 逐部件包围盒投影到 NDC，断言没有被挤出画面
- 清屏成纯黑后单独渲染视图模型 / 敌人，统计非黑像素与包围盒
- 在独立纯黑 WebGL2 framebuffer 只渲染一条曳光并读取像素
- 用「手工放一个红方块」先自检测量方法本身有效，再测真实对象
- Esc 暂停走完整输入链路（真实 keydown → 主循环 → 菜单可见）

`tools/test-ui-input.mjs` 现在就有这条自检：方法不灵时 A 组先失败，
避免再出现"测试通过但功能没用"的情况。

## 7. 地图与模型导入通道

### 7.1 地图格式

地图是纯 JSON（`MAP_FORMAT_VERSION = 1`），字段见 `docs/CONTRACTS.md` §8.1。
程序化生成入口 `src/maps/builtin-maps.js` 的 `generateMap({seed, biome, archetype, size, tier})`。

**要换成手工地图**：写一个同样结构的 JSON，调 `world.load(mapData)` 即可，
渲染与碰撞会全部按新数据重建（地形三角、盒体、点位、光照）。

### 7.2 外部模型导入（GLB）

1. 把 `.glb` 放进 `public/models/`
2. 在 `public/models/manifest.json` 里登记：

```jsonc
{
  "visuals": [
    { "id": "tower_a", "file": "tower_a.glb", "category": "structure",
      "collision": { "mode": "box" },        // none=纯装饰 / box=用包围盒生成碰撞
      "placements": [ { "pos": [10,0,-20], "yaw": 0.5, "scale": 1.0 } ] }
  ],
  "replace": { "prop.crate": "crate_hd.glb" }  // 用高模替换某个程序化道具
}
```

3. 刷新页面即生效。仓库自带一个示例：`node tools/make-sample-glb.mjs`
   会生成 `tank_cluster.glb`（76 三角面的储罐），并在关卡里摆放 3 个实例。

模型规范：单位米、Y 向上、原点在脚底、面朝 `-Z`、单文件 GLB、三角面 < 50k。
**程序化几何始终是碰撞的唯一权威**，导入模型默认只替换渲染 —— 避免美术资源改坏判定。

## 8. 性能设计（为什么能跑到高帧率）

| 手段 | 效果 |
|---|---|
| **状态批处理渲染** | 每帧把绘制请求按 (mesh, shader变体) 去重合并成批次 → 整个静态世界 **1 次 draw call** |
| **实例化** | 单位形状 + 实例矩阵缩放，988 个静态盒体 / 1300+ 动态实例只需个位数 draw call |
| **单次上传** | 实例数据先写 CPU 端 staging 数组，帧末一次 `bufferSubData` |
| **零每帧分配** | 粒子/弹道/曳光全部 SoA + 池化 + 原地压缩；热路径无对象分配 |
| **共享网格库** | 粒子/曳光/贴花/敌人/道具共用 13 个单位形状 |
| **固定步物理** | 1/128 秒，单帧最多 6 步（防死亡螺旋），相机在帧内插值 |
| **轻量着色** | 平直 Lambert + 半球环境光 + 边缘光 + 距离雾 + 程序化面板格；无阴影贴图、无后处理 |
| **距离淡出细节** | 程序化网格按距离淡出，避免远景摩尔纹 |

实测（无头 Chrome + SwiftShader **纯软件光栅化**，仅代表管线健康度，非真机帧率）：
满载 18 敌人 + 粒子场景下 **11 次 draw call / 31k 三角形 / 1304 实例**。
真机（独显/集显硬件光栅化）下这一负载极易达到 144+ FPS。
**真机帧率请在本机浏览器里按 `F3` 看调试面板实测。**

## 10. 调试与自动化接口

浏览器控制台可用 `window.__IRONFALL__`：

```js
__IRONFALL__.debugState()                    // 全量运行状态（帧率/draw call/玩家/AI/导演）
__IRONFALL__.setAutomationMode(true)         // 关掉指针锁定要求，允许程序化输入
__IRONFALL__.startRun()                      // 直接开局
__IRONFALL__.simulate(2.0, [                 // 无头推进：不依赖真实帧率
  { seconds: 1.0, moveY: 1, sprint: true },
  { seconds: 0.3, jump: true, fire: true },
  { seconds: 0.3, crouch: true, dash: true, grapple: true },
])                                           // 语义字段会被翻译成按键注入真实 Input 通道
__IRONFALL__.measureFps(2000)                // 测一段时间的真实渲染帧率
__IRONFALL__.renderOnce()
```

`simulate()` 走的是与真机完全相同的输入路径（`Input._injectKey` → `readInputInto` → `stepPhysics`），
所以它能覆盖输入层本身的 bug —— 实际上正是靠它抓到了「跳跃/冲刺边沿被固定步循环吃掉」的问题。

数值探针：`game.nanSentinel = true` 会在物理步边界抓第一个非有限值并记录上下文
（曾经用它定位到 `getCameraRecoil()` 字段名不一致导致的 NaN）。

## 12. 已知限制

- **`Ctrl+W` / `Ctrl+T` / `F11` 无法拦截**：这些是浏览器保留快捷键，网页没有权限吞掉。
  游玩时请避免误按（`Ctrl+W` 会直接关掉标签页）。
- 指针锁定需要浏览器授予权限；关闭菜单时会自动请求恢复，若浏览器拒绝，再点击一次游戏画面即可。
- 无阴影贴图与后处理（为帧率做的取舍）；光照是平直 Lambert + 半球环境光。
- 模型仍是程序化几何（箱体/圆柱/球/楔形），但枪械、角色、敌人、物资和危险区已采用分层部件；**美术资源仍可通过 §7.2 通道继续替换**。
- 敌人使用简化导航（贴地 + 绕障），没有 A* 寻路网格。
- 音效为纯程序化合成，无音频素材。
- 无网络对战/存档云同步。
- `tools/headless-check.mjs` 的帧率数字来自 SwiftShader 软件渲染，**不能当作真机性能**。
- 无头环境无法验证真实指针锁定（headless Chrome 会拒绝），
  因此 `test-ui-input.mjs` 只校验 API 与提示逻辑，真机行为需要人工确认。
