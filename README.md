# IRONFALL 2.1.1 · 钢铁远征

IRONFALL 是一个原生 WebGL2 第一人称搜打撤 / Roguelike 游戏。2.0 版使用独立无边框 Chromium 游戏窗口，玩法重心为 Apex 风格枪战与机动、十关战役、地图搜刮、撤离带出和局外成长。

> Windows 10/11；需要 Chrome 或 Edge。游戏代码零第三方运行时依赖。首次使用发布包时，如系统没有 Node.js，启动脚本会下载便携运行环境。

## 2.1.1 通用联机（协议 2，双方必须同版）

一个通用安装包供所有房主和朋友使用，不再固化某个人的穿透地址或证书。

1. 双方只需双击 **开始游戏.cmd**，进入 **主菜单 → 局域网联机**。
2. 房主填写房间名，点击 **创建房间**，游戏自动启动本机 18200 联机服务；穿透客户端仍需运行，目标为 127.0.0.1:18200。
3. 房主在服务器框填写完整 HTTP/HTTPS 穿透地址，按需选择 .crt 公开证书（绝不能选 .key），点击 **导出邀请**。房间名要与创建时一致。
4. 将下载的邀请 JSON 发给朋友。朋友在游戏里选择文件，点击 **确认导入并连接**，核对目标与证书指纹后确认。房主无需导入自己的邀请。
5. 地址或证书变化时重新导出即可，无需重新打包；HTTPS 校验保持开启，不安装系统证书。仍需可达的服务器和兼容的穿透节点。

修复晚加入缺失 SESSION/敌人快照与暂停菜单不刷新；同步名牌、枪/刀/治疗手持物、开火轨迹与抓钩绳索。友伤开启，玩家击杀不计小怪死亡额度，可无限部署；小怪/环境死亡达到 3 次后只能观战，全员淘汰后房主重开。个人部署保留当前地图/敌人/任务。

适合可信朋友合作或对战，客户端权威部分不提供竞技反作弊保证。已完成纯逻辑专项与 HUD 检查，真实双机完整游戏、视觉效果和长时间网络稳定性待玩家验证。

## 快速开始

### 开发目录

需先安装 Node.js；开发目录的入口不负责自动下载运行环境。

双击：

```text
开始游戏.cmd
```

单机启动器默认从 `127.0.0.1:18240` 启动，并使用独立的 `app-profile-v2` 浏览器配置打开无地址栏、无标题栏的全屏游戏窗口。启动器会核验精确构建版本；发现端口上是旧实例时会保留旧进程并自动寻找后续空闲端口，绝不会再把新版本错误交给旧服务器。

如端口被其他程序占用，可在命令行先设置：

```bat
set IRONFALL_PORT=19080
开始游戏.cmd
```

### 发布包

下载并解压 `IRONFALL-2.1.1-offline.zip`，双击其中的 `开始游戏.cmd`。

## 2.0 已实现内容

### 局域网与公网联机（合作，最多 4 人）

- 双击 `开始游戏.cmd`，在大厅创建房间，自动启动本机服务器。
- 同网段的朋友用 Chrome/Edge 打开那个地址，**主菜单 → 8 局域网联机 → 2 加入房间**即可，无需输入 IP。
- **公网也能玩**：把完整游戏目录或完整发行包放到有公网 IP 的机器上，运行 `node tools/lan-server.mjs 18200` 并放行端口；
  也可以在大厅的「服务器」输入框里直接填 `1.2.3.4:18200` 连到任意一台公网服，
  不必先从对方那儿打开游戏。大厅会列出已保存服务器及其在线人数。
- 公网服上**第一个连上的人自动成为房主**（由服务器判定），由他跑敌人与刷怪导演。
- 房主点“开始远征”，房客自动加载**完全相同的任务与地图**（种子由房主下发）。
- 每个客户端模拟自己的玩家，远程表现仍受网络延迟、丢包与同步策略影响；
  敌人与刷怪导演由房主权威模拟，房客按快照插值显示。
- 敌人会就近选择队友作为目标；伤害由房主判定后转发给本人结算，不会误记到别人身上。
- 队友以第三人称模型显示（21 部件整身人形），大厅提供队友血量/延迟列表与队伍聊天。
- 详细设计与已知边界见 [`docs/LAN.md`](docs/LAN.md)。

### 校园网 / NAT 内网穿透

校园网外的朋友通常无法直接访问你的校园网 IP。推荐使用支持 WebSocket 流量的 **TCP 穿透**，无需修改本地服务器端口：

1. 房主完整解压发行包。首次缺少 Node 时，先运行“开始游戏.cmd”完成环境下载，再退出游戏。
2. 运行“开始游戏.cmd”，在联机大厅创建房间；保持游戏运行。
3. 穿透工具配置：类型 **TCP**，本地地址 **127.0.0.1**，本地端口 **18200**。
4. 房主可连接本机 127.0.0.1:18200 并创建房间；队友从本地游戏窗口的联机大厅输入穿透服务分配的 **域名:公网端口**。双方使用相同房间名（默认 default），房主开始远征。
5. 公网端口不一定是 18200；以穿透工具给出的地址为准。不要把房主的 127.0.0.1 发给队友。

完整 HTTPS/WSS 地址省略端口时使用 443，HTTP/WS 地址使用 80；裸主机名默认 18200，显式填写的端口保持不变。HTTPS 穿透需要支持 WebSocket 升级；HTTPS 页面不能连接明文 ws://，TCP 穿透建议从本地游戏窗口进入。校园网可用性取决于网络策略，请遵守学校规定。

### 启动与联机排错（2.1.1）

- 游戏窗口默认端口 18240，游戏内创建的联机服务固定为 18200；穿透指向后者。
- 创建房间遇到端口占用时仅复用已确认的联机服务，不盲目关闭其他程序；旧协议客户端必须更新。
- 公网浏览器页面不提供本机服务管理；开房、证书邀请导入请从新版“开始游戏”进入。
- 创建失败时检查 18200 是否被其他程序占用；朋友连接失败时核对穿透状态、地址、证书有效期和系统时间。
- 发布包和开发仓库均只保留“开始游戏.cmd”一个入口；开房与邀请操作在游戏大厅完成。
- 逻辑与打包检查不等于真实双机体验验收；多人长时间同步仍由玩家测试。

### 战役与搜打撤

- 10 个真实可进入的战役关卡，覆盖 5 种生物群系与 6 种地图原型。
- 主菜单“战役选择”可重玩已解锁关卡；成功撤离自动解锁并推进下一关，第 10 关目标与首领全部完成后自动结算回主菜单，显示结局；下一轮从第一层开始，保留仓库与局外成长。
- 任务、撤离点、补给站均有 HUD 方位标识和世界模型。
- 摧毁目标可被武器实际打坏；回收、守卫、占领类目标有对应交互和进度，而不是只显示文字。
- 成功撤离时，有限背包物资、获得的稀有枪械和已装配件进入局外仓库；下一次部署自动取出。阵亡时本次部署物资丢失。

### 局外成长

主菜单“局外军械库”可用撤离获得的远征点数购买 10 类永久改件：

- 移速、生命、护盾、合金获取
- Dash 次数、抓钩距离
- 武器伤害、击杀回血
- 撤离读条速度、改件稀有度

所有数值会从下一次部署开始进入玩家、武器或单局系统的真实 modifier 流程，并持久化到本地存档。

### 敌人与战斗

导演会按关卡逐步生成 6 种敌人：步兵、虫群、盾卫、飞行器、狙击手、重装单位；第 5 关起完整兵种池开放。敌人出生在其有效攻击距离之外。

- 玩家与人形敌人使用一致的 100 生命 / 75 护盾基础值（局外改件可提高玩家上限；守关首领有额外生命与护盾）。
- 伤害先扣护盾再扣生命；盾击、破盾、肉体命中、爆头和击杀使用不同反馈音效。
- 破盾为明显的高音量玻璃碎裂声。
- 命中后显示分段护盾条与生命条；1 秒未受击或持续遮挡 0.4 秒后隐藏。
- 死亡烟雾已移除；脚底黑烟仅保留很小的低密度反馈。

### 武器

可用枪械：

| 武器 | 弹匣 | 基础伤害 | 说明 |
|---|---:|---:|---|
| R-99 | 24 | 18/发 | 1080 RPM，远距离衰减已降低，无枪口火光 |
| 平行步枪 | 35 | 22/发 | 中距离重型步枪 |
| Volt | 35 | 由武器数据决定 | 地图掉落，可真实换装开火 |
| 和平捍卫者 | 6 | 多弹丸 | 地图掉落，可真实换装开火 |
| 长弓 | 5 | 精确单发 | 地图掉落，可真实换装开火 |
| 哨兵 | 8 | 60/120 | B 键整匣充能后 90/180，4× 狙击镜 |

- 备弹无限；换弹时间：R-99 0.6 秒、平行步枪 1 秒、哨兵 2 秒。
- 换弹含取下、丢弃、抓取、插入、就位和拉栓动作，各阶段有独立音效。
- 哨兵充能和剩余强化次数会在切枪、普通换弹后保留；拉栓完成时刚好恢复开火。
- 所有枪械使用安装在枪体上的物理瞄具；右键 ADS 时移动速度为腰射的 50%。狙击灵敏度可在设置中单独调整。
- 连射弹道与屏幕后坐方向一致，曳光尺寸已缩小，避免遮挡视野。
- 开枪保留可控的枪械后坐与压枪反馈，但不再叠加随机屏幕震动。
- 已修复命中墙壁/地面时错误引用伤害变量导致的扣弹后异常；射击逻辑包含后续冷却与输入修复，并非完全等同于 1.0。
- 主菜单和 Esc 暂停菜单均提供“退出游戏”，会释放鼠标锁并关闭独立窗口。

### 配件与背包

Tab 打开 6×4 背包：

- 单击使用或安装。
- 拖动整理；配件可拖到武器卡片安装，也可拖回背包卸下。
- 右键丢弃，或拖到背包外 / 丢弃区。
- 鼠标悬停显示真实用途、数值、兼容武器和操作方法。

配件包含轻型弹匣、重型弹匣和狙击充能电芯 I/II/III：

- 弹匣 I/II/III：+3 / +5 / +8
- 电芯 I/II/III：充能时间 ×0.88 / ×0.78 / ×0.68
- 高等级可替换低等级，旧配件回到背包；低等级不能覆盖高等级。
- 另有 1× 全息瞄具、战术刀、装甲板、情报核心和枪械掉落。

### 治疗

- 轻按 5 使用当前选择；长按 5 打开四向治疗轮盘。
- 上：注射器（1 秒，+25 生命）
- 下：小型护盾电池（1 秒，+25 护盾）
- 左：医疗包（3 秒，生命回满）
- 右：护盾电池（2.5 秒，护盾回满）
- 四种战术治疗资源均为无限，HUD 与实际一致显示 `∞`。
- 使用期间减速，必须读条完成才生效；开火、开镜、换弹或切枪会打断。
- 起始、持续和完成阶段都有独立音效与第一人称道具动作。
- 护盾脱战后按每秒 10% 自动恢复；残血不会自动切换治疗道具。

### 机动

- 疾跑有加速过程和较低速度上限，不会按下即满速。
- 达到速度门槛后才能滑铲；起滑有受控小加速，随后衰减。
- 正确的“疾跑 → 滑铲 → 跳跃”是普通地面移动的最快方式。
- 下坡滑铲沿真实坡面最陡方向助推，速度投影到坡面；坡折会继续消费剩余切向位移并向下贴地，避免卡脚。
- 支持滑铲跳、二段跳、Dash、墙爬和 Titanfall 2 风格短时墙跑。
- Dash 冷却已降低刷新频率，避免无限高速循环。
- 抓钩有绳索模型；命中场景会牵引玩家，命中敌人会按质量比例同时拉近双方。距离小于约 2m，或视角脱离锚点超过 1 秒会断钩。
- 角色静止时不会沿斜坡自行漂移；墙体粘连和进入实体会由碰撞解算与脱困逻辑处理。

Esc 由 Game 的单一状态机处理：游玩中打开设置并暂停、释放鼠标；菜单中关闭并返回游戏。独立窗口不调用网页 Fullscreen API，因此 Esc 不会导致窗口小窗化。返回游戏时会立即请求锁定鼠标，未锁定则 1 秒后自动重试。

## 设置

- 鼠标灵敏度范围 `0.00005–0.006`，默认 `0.0012`。
- 狙击 ADS 灵敏度倍率可独立设置，默认 35%。
- Y 轴默认不反转；可手动打开“Y 轴反转”。
- 可调整 FOV、主音量、帧率上限、画质。
- 独立启动器默认无边框全屏，避免普通浏览器右键手势、标签快捷键与 Alt+Space 系统菜单干扰。

## 存档

进度存储在 IRONFALL 专用 Chrome/Edge 配置目录的 localStorage 中，包含：

- 十关解锁和当前选择
- 远征点数、合金、统计
- 10 类永久改件
- 局外仓库和最近一次撤离装配位置
- 设置

2.0 会自动迁移旧版 v1 存档的已有资源、改件和解锁数据。

## 技术结构

- `src/main.js`：生命周期、菜单、远征与系统编排
- `src/player.js`：移动、碰撞、墙跑、滑铲、抓钩
- `src/weapons.js`：枪械状态、ADS、充能、换弹、视图模型
- `src/inventory.js`：掉落、背包、配件、武器换装与带出数据
- `src/save.js`：局外成长、十关进度、仓库和存档迁移
- `src/enemies.js` / `src/director.js`：六兵种与刷新导演
- `src/maps/builtin-maps.js` / `src/world.js`：地图、地形、岩浆、目标与碰撞
- `src/audio/audio.js`：程序化 WebAudio 音效
- `src/ui/hud.js`：HUD、设置、战役选择和局外军械库
- `src/net/`：局域网联机（传输、协议、会话、队友模型），只依赖 `core/*`
- `tools/lan-server.mjs`：零依赖局域网服务器（静态站点 + WebSocket 房间中继）
