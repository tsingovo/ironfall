# IRONFALL 发行包 · 2.1.6

本地包：IRONFALL-2.1.6-offline.zip。尚未上传或创建线上发行版。

解压到新目录，只需双击“开始游戏.cmd”。主菜单 → 局域网联机：
- 房主填写房间名，创建房间自动启动 18200 服务。
- 填写完整穿透地址，按需选公开 .crt，导出邀请发给朋友。
- 朋友选择邀请 JSON，确认导入并连接；不用再运行任何联机 CMD。
- 穿透软件仍由房主配置运行，目标 127.0.0.1:18200。不要分享 .key 私钥。
